# 真模型模式（upstream）

本地那个字符级小模型只会复读语料，所以 API 默认走「真模型转发」：
请求进到本服务后，转发给一个 OpenAI 格式的推理服务，答案再按原格式返回。
对外地址和 Key 都不变。

## 开关与环境变量

| 变量 | 默认值 | 作用 |
|---|---|---|
| `XL_BACKEND` | `auto` | `auto` 先用真模型失败回落本地；`upstream` 只走真模型；`local` 只走本地 |
| `XL_UPSTREAM_URL` | `https://text.pollinations.ai/openai` | 推理服务地址（OpenAI 兼容） |
| `XL_UPSTREAM_MODEL` | `openai` | 传给对方的 model 名 |
| `HF_TOKEN` | 空 | 走 Hugging Face router 时填 token |
| `XL_SYSTEM_PROMPT` | 见代码 | 给模型的人设，默认自称“雄灵一号” |

## 换成 Hugging Face（可选，更稳）

```
XL_UPSTREAM_URL=https://router.huggingface.co/v1/chat/completions
XL_UPSTREAM_MODEL=Qwen/Qwen2.5-1.5B-Instruct
HF_TOKEN=hf_xxxxxxxx
```

## 行为说明

- 真模型调用超时 / 报错 → 自动回落到本地小模型，`/v1/models` 的 `upstream_error` 会写明原因；
- `/health` 的 `backend` 字段显示当前生效的通道（`upstream` 或 `numpy-char-bigram`）；
- 每个响应里带 `provider` 字段，方便排查到底谁答的；
- 隐私提醒：走免费通道时提示词会发给第三方服务，不要发敏感内容。
