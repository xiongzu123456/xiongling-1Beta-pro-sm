# 国内能打开的免费部署方案

Render 在国内经常打不开。下面两个平台在国内访问正常，且都有免费额度。

---

## 方案 A：魔搭创空间（推荐，国内最快，CPU 完全免费）

官方文档：https://www.modelscope.cn/docs/studios/docker.md

1. 打开 `modelscope.cn`，手机号或支付宝登录；
2. 按提示绑定阿里云账号并完成**实名认证**（Docker 创空间强制要求，不做没法用）；
3. 进入「创空间」→ 创建 → SDK 选 **Docker**；
4. 把本仓库文件全部上传（`api/Dockerfile` 已经把端口设成 7860，符合平台要求，不用改）；
5. 配置里加环境变量：

```
XL_API_KEY=sk-xionglingautobaiduscshumi
XL_BACKEND=auto
XL_UPSTREAM_URL=https://text.pollinations.ai/openai
XL_UPSTREAM_MODEL=openai
```

6. 点部署，等构建完成，公网地址形如：

```
https://你的用户名-空间名.ms.show
```

**两个必须注意的坑**
- 端口只能是 `0.0.0.0:7860`，不能用 8080（平台自己占用）；
- 魔搭网关会拦 `Authorization` 请求头，所以调用时**统一用 `x-api-key`**（本项目已支持，前端页面用的就是它）。

---

## 方案 B：ClawCloud Run（GitHub 登录，无需实名）

1. 打开 `clawcloud.run`，用 **GitHub 账号**登录（有每月 5 美元免费额度，不用绑卡）；
2. App Launchpad → Create App → Deploy from GitHub → 选仓库 `xiongling-1Beta-pro-sm`；
3. 构建方式选 Dockerfile，路径 `api/Dockerfile`，端口 `7860`；
4. 环境变量同上四个；
5. 部署完给一个 `https://xxx.clawcloud.run` 的地址。

---

## 部署完怎么验

```bash
curl https://你的地址/health
```

返回里 `"backend":"upstream"` 就说明真模型在工作；如果是 `"numpy-char-bigram"` 说明没连上外部推理服务，把 `XL_BACKEND=local` 也行（但回答会退回念经水平）。

然后把地址填进网页端「设置」里的 API 地址栏，别人打开网页就能用。

---

## 如果平台限制访问外网

魔搭、ClawCloud 的容器默认能出网（装依赖要用），但个别情况下会限制。
真模型连不通时，`/v1/models` 的 `upstream_error` 会写明具体错误；届时可换成：
- 把 `XL_UPSTREAM_URL` 换成自己能访问的 OpenAI 兼容服务；
- 或 `XL_BACKEND=local` 走本地模型兜底。
